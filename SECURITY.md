# Security Policy

## Reporting Security Vulnerabilities

If you discover a security vulnerability in this website or repository, please report it responsibly to:

**Email:** security@vamikaexports.com (or info@vamikaexports.com if custom domain is in use)

**Please do NOT:**
- Post vulnerabilities publicly on GitHub issues
- Share sensitive details on public forums
- Attempt unauthorized access to any systems

**Please DO:**
- Provide detailed description of the vulnerability
- Include steps to reproduce (if applicable)
- Allow reasonable time for a fix before disclosure (typically 30–60 days)

## Security Measures

This website implements the following security practices:

- **SSL/TLS Encryption** — All data in transit is encrypted (HTTPS)
- **Content Security Policy (CSP)** — Prevents injection attacks
- **HTTP Security Headers** — X-Frame-Options, X-Content-Type-Options, Referrer-Policy
- **Input Validation** — All forms are validated server-side
- **Regular Updates** — Dependencies updated for known vulnerabilities
- **No Sensitive Data** — No hardcoded secrets or credentials in repository
- **Secure Hosting** — Deployed on Vercel with automatic SSL and DDoS protection

## Data Protection

- Personal data is handled according to our Privacy Policy
- No passwords are stored on this website
- All transactions use secure payment gateways
- Data retention complies with Indian export regulations

## Compliance

This website complies with:
- GDPR (General Data Protection Regulation) for EU visitors
- Indian data protection standards
- Export control regulations
- Industry best practices for web security
