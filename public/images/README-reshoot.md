# Photo reshoot list

**even-light shots: one dry and one wet** of each tile. Shoot in overcast light or
open shade, so there are no dappled shadows.

Keep the same file names (and regenerate the `-thumb.jpg` versions) so the site
picks them up without code changes. Alt text and captions live in `src/config.js`.

Tick each one after checking it. Mark it **Reshoot** if it has heavy shadows.
